# mppnet/frontend

This is the frontend browser source code for [MultiplayerPiano.net](https://multiplayerpiano.net). This repository does not contain any server logic. Feel free to create a fork.

[License](/LICENSE)

## Issues

If you are reporting a bug, create a new issue [here](https://github.com/mppnet/frontend/issues/new). Search for your issue before creation to make sure it was not already created by someone else.

Please do not create issues with AI, we will probably just close it.

## Contributing

Please make changes to the `dev` branch and make pull requests to there. All changes on the `dev` branch go live here: https://dev.multiplayerpiano.net

From there, a pull request to `main` will be created, where it will be merged into the production environment here: https://multiplayerpiano.net

Not every change will be merged. Changes are merged at our discretion. Any pull requests to the `main` branch are subject to be redirected to `dev` at any point.
